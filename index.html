I found the leak in my own model, and the number I published didn't survive it.

A model that is obviously wrong is easy to catch. A model that is quietly wrong — right about the easy cases, useless on the hard ones — passes every check you run and costs you a quarter before anyone notices.

What I do about that:

  • Hold out whole clients, and measure what holding them out actually bought.
  • Quote only numbers that reproduce from a clean clone.
  • Name the limits, with a fix beside each, in the repo.
  • Label every figure with the slice it came from.

What that discipline cost me

On my own build it cost me my headline number. ROC AUC 0.750 fell to 0.565 once I removed the rows that could never have declined, and the Precision@50 of 0.680 I had already published is withdrawn. Both are written up in full, with the code that produced them.

Where the evidence is

  • Three cases — the leak, the split that was measured rather than assumed, and the feature set I refused to build on.
  • Seven named failure modes — each with a fix beside it, or an honest note that no fix is applied.
  • A scoped trial — one dataset, one ranking question, free at that size.

  • The leakage notebook — five tests, all five results
